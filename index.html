STEP 1 — 判定方法上から順番に確認してください

PHASE 0

まず「接触導線不足」を確認する

  • 直近30日で接触した女性が0〜2人（Q3がA・B）
  • 1分以上の会話が成立した回数が0〜2回（Q4がA・B）
  • 女性を誘ったことがない（Q8がA）
  • 二人で会えていない（Q10がA）

この場合、恋愛力以前に観測データが不足しています。拒絶されているのか、安全ライン未満なのかを判定できるだけの接触回数がありません。

PHASE 1

次に「拒絶ライン未満」を確認する

  • 目を合わせない、会話をすぐ切られることが多い（Q5がA・B）
  • そもそも会話が始まらない（Q6がA）
  • 女性からのリアクションがほぼない（Q7がA）

この段階では、口説き方より先に、拒絶・警戒・不快を減らす必要があります。

PHASE 2

次に「安全ライン未満」を確認する

  • 会話は始まるが続かない（Q5がB・C、Q6がB・C）
  • 相手から質問がほぼ返ってこない（Q7がA・B）

この段階では、恋愛の空気を出す前に、まず「人として普通に関われる男」になる必要があります。

PHASE 3

次に「男としての候補ライン未満」を確認する

  • 会話はできるが、恋愛の空気にならない（Q5がC・D、Q6がD、Q7がC・D）
  • 誘っても具体的な日程にならない、または会えても次につながらない（Q8がB・C・D、Q9がB・C、Q10がB・C）

この段階では、優しさや誠実さを増やすだけでは足りません。安全性を保ったまま、男としての輪郭を出す必要があります。

PHASE 4

最後に「長期伴侶ライン未満」を確認する

  • 二人で会える・関係が進むことがある（Q10がD・E、Q12がD・E）
  • しかし、付き合うところや継続の場面で崩れる（Q13がD・E）

この段階では、男としての魅力だけでは足りません。長期的に人生へ入れても大丈夫だと思われる信頼・安定・関係運営能力が必要です。

STEP 2 — 詳細解説該当フェーズを開いて読んでください

0 接触導線不足 +

あなたの暫定フェーズ

今は恋愛力以前に、観測データが不足している可能性が高い状態です。女性との接触回数が少なすぎるため、拒絶されているのか、安全ライン未満なのか、男として見られていないのかを判定できません。これは「恋愛力が低い」というより、まだ診断できるだけの材料がない状態です。

よくあるボトルネック

恋愛の勉強をしているのに、実際の接触データが増えていない。会話術・LINE術・口説き方・デートプラン・告白のタイミングを学んでも、接触回数が少なければ、自分がどこで落ちているのか分かりません。問題は「恋愛テクニック不足」ではなく、観測回数不足です。

やらなくていい努力

今すぐ高度な口説き方を学ぶ必要はありません。LINEテクニック、告白文、デート中の駆け引きより、まずは女性と自然に接触する導線を作る方が先です。

まず1週間やる練習

  • 店員・美容師・受付・スタッフと短く会話する
  • 趣味・イベント・勉強会に1つ申し込む
  • マッチングアプリならプロフィール改善＋10〜30いいねを実行する
  • 女性がいる場に1回出る

目的はいきなりデートに進めることではなく、まず自分の現実の反応データを集めることです。

有料診断で見るべきログ

  • 直近30日で女性と接触した回数・場所・会話内容・相手の反応
  • 自分から接触を増やせない理由
  • マッチングアプリならプロフィール・写真・いいね数・マッチ数
1 拒絶ライン未満 +

あなたの暫定フェーズ

恋愛対象になる以前に、女性側の警戒・不快・拒絶が出ている可能性があります。女性が求めているのは魅力より先に「近くにいても大丈夫」「話しかけられても怖くない」「断っても引いてくれそう」という最低限の安心です。

よくあるボトルネック

会話術ではなく、不快要因です。清潔感、髪型、服装、口臭・体臭、歯・肌・爪、姿勢、声量、表情、距離感、目線、断られたときの引き方。本人は普通に接しているつもりでも、女性側の身体感覚では「近づかれたくない」「圧がある」と判定されていることがあります。

やらなくていい努力

口説き文句、恋愛テクニック、LINEの駆け引き、強いアプローチを学ぶ段階ではありません。拒絶ラインを超えていない状態で使うと、警戒や不快を強めやすいです。

まず1週間やる練習

  • 外見・清潔感の点検（髪・眉・髭・鼻毛・歯・口臭・体臭・服のヨレ・靴・爪）
  • 距離感の練習（店員・受付などとの短いやり取りで、圧をかけずに気持ちよく終える）
  • 撤退の練習（反応が薄ければ追わずに引く）

目的は惚れさせることではなく、「この人は近くにいても大丈夫」と感じられる男になることです。

有料診断で見るべきログ

  • 服装・髪型・写真／会話開始時の相手の反応
  • 距離感・声量・表情・姿勢／断られたときの対応
  • マッチングアプリなら写真・自己紹介文・マッチ率、対面なら声かけ文と初期反応
2 安全ライン未満 +

あなたの暫定フェーズ

女性と会話する場は作れているものの、会話が続かない、相手から質問が返ってこない、空気が重い状態です。恋愛対象になる前に、まず「人として普通に関われる」「話していて負荷が少ない」と感じられる必要があります。

よくあるボトルネック

会話の重さです。自分語りが長い、質問攻めになる、すぐ正論・解決策を言う、沈黙を怖がりすぎる、相手が引いているのに追ってしまう。「悪い人ではないけど、話していて疲れる」と感じられやすい状態です。

やらなくていい努力

恋愛の駆け引き、強い口説き、告白、長文LINE、深い自己開示を頑張る段階ではありません。安全ライン未満で恋愛感を出すと、重さや圧として受け取られやすいです。

まず1週間やる練習

  • 自分の話は30秒以内に収める
  • 質問だけでなく、自分の感想を1つ挟む
  • 正論や解決策をすぐ出さない
  • 会話が温まったところで、自分から気持ちよく終える
  • 反応が薄いときは追わない

目的は、相手に「この人とは普通に話せる」と感じてもらうことです。

有料診断で見るべきログ

  • 実際の会話ログ・LINEのやり取り
  • 自分の話の長さ／質問と自己開示のバランス
  • 会話が切れるポイント／誘う前の関係性
3 男としての候補ライン未満 +

あなたの暫定フェーズ

女性と普通に話せる。嫌われてはいない。でも恋愛にならない。二人で会う流れにならない、会えても次につながらない。「いい人」「話しやすい人」で止まりやすい状態です。

よくあるボトルネック

無害化です。なんでも相手に合わせる、自分の提案がない、目線・声・姿勢・間が弱い、冗談や軽いからかいがない。女性側からは「人としてはいいけど、男としては見られない」「ドキドキしない」となりやすいです。

やらなくていい努力

さらに優しくする、さらに誠実アピールする、相手の機嫌を取り続ける、告白で一発逆転を狙う、という努力はズレやすいです。

まず1週間やる練習

  • 小さな提案をする（「駅前のカフェで30分だけ」「土曜の夕方あたり」「合わなければすぐ解散でOK」）
  • 身体性の改善（姿勢・声・目線・歩き方・服・髪型。特に髪型と服は即効性が高い）
  • 会話に軽さを入れる（媚びずに自分も楽しむ、少し茶化す。下ネタや圧の強い口説きは不要）

目的は、相手に「この人は安全だけど、ただの無害な人ではない」と感じてもらうことです。

有料診断で見るべきログ

  • 誘い方の文章／誘ったときの相手の反応
  • 二人で会う前後の会話ログ・初回デートの流れ
  • 服装・髪型・写真／声・姿勢・目線・間／次につながらない原因
4 長期伴侶ライン未満 +

あなたの暫定フェーズ

女性と二人で会える。恋愛関係や性的関係に進むこともある。しかし付き合うところで崩れる、または付き合っても継続しない。信頼・安定・生活力・感情コントロールで問題が出やすい状態です。

よくあるボトルネック

関係運営の不安定さです。返信が遅いだけで不安になる、嫉妬で詰める、約束や時間を守れない、生活・仕事・お金・健康の運用が不安定。短期的に魅力があっても、「この男を人生に入れて大丈夫か」が見られています。

やらなくていい努力

さらに刺激を増やす、さらに口説く、相手をコントロールする、という方向は危険です。必要なのは刺激ではなく、信頼・安定・言行一致です。

まず1週間やる練習

  • 小さな約束を確実に守る
  • 不安を相手にぶつける前に一度止める（返信が遅い、反応が薄いときに即追撃しない）
  • 生活の最低運用を整える（睡眠・食事・部屋・お金・仕事・健康）

目的は、相手の人生システムが「この男を中に入れても安全で、むしろ良くなる」と判断することです。

有料診断で見るべきログ

  • 関係が崩れた場面／返信・LINEのやり取り／約束や予定調整のログ
  • 不安になったときの行動／相手から言われた不満
  • 生活・仕事・金銭・健康の状態／衝突時の会話ログ

CLOSING NOTE最後に

この診断は、あなたを否定するためのものではありません。目的は、努力の順番を間違えないことです。

  • 拒絶ライン未満なのに、口説き方を学ぶ。
  • 安全ライン未満なのに、恋愛テクニックを使う。
  • 男として見られていないのに、誠実さや告白で押す。
  • 長期伴侶として不安定なのに、将来を語る。

こうした努力はズレやすいです。重要なのは、自分が今どのラインで落ちているのかを見て、正しい順番で改善することです。これは暫定診断であり、正確な判定には実際の会話ログ・誘い方・相手の反応・プロフィール・外見・接触導線を見る必要があります。
